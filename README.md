# UNIFLOW-BEHAVE

## AI-Based Detection of Cyber Threats in Unidirectional IP Traffic

UNIFLOW-BEHAVE is a cybersecurity solution designed to detect potential cyber threats in unidirectional IP traffic using passive network traffic analysis, behavior profiling, machine learning, and rule-based detection.

## Problem Statement

**SIH26145 – AI-Based Detection of Cyber Threats in Unidirectional IP Traffic**

In unidirectional network environments, network activity can be observed but the source cannot be directly interacted with. UNIFLOW-BEHAVE addresses this challenge by analyzing network traffic passively and identifying suspicious behavior.

## Key Features

- Passive network traffic analysis
- 5-second feature and behavior profiling
- Flow generation and feature extraction
- Behavior analysis
- Random Forest-based detection
- Rule-based threat detection
- Risk scoring and drift analysis
- Explainable alerts
- Live traffic analysis
- Demo analysis
- Interactive security dashboard

## Dashboard
